# Iraq Medical Clinic SaaS

منصة SaaS أولية لإدارة العيادات الطبية في العراق، مبنية بـ Next.js وTypeScript وTailwind CSS وPrisma.

## ماذا تحتوي هذه النسخة؟

- واجهة بداية عربية/إنجليزية عبر `/ar` و`/en`.
- تصميم RTL افتراضي مناسب للعربية.
- تصور SaaS متعدد العيادات والفروع والمستخدمين.
- وحدات أولية: المرضى، المواعيد، الزيارات الطبية، الفواتير، والصلاحيات.
- قائمة تخصصات طبية قابلة للتوسع مع قوالب حقول لكل اختصاص.
- مخطط Prisma أولي لقاعدة PostgreSQL.
- بوابة المريض مؤجلة حالياً حسب نطاق النسخة الأولى.

## التشغيل محلياً

```bash
npm install
npm run dev
```

ثم افتح:

- `http://localhost:3000/ar`
- `http://localhost:3000/en`

## قاعدة البيانات

انسخ ملف البيئة:

```bash
cp .env.example .env
```

ثم عدل `DATABASE_URL` لقاعدة PostgreSQL الخاصة بك، وبعدها:

```bash
npm run db:generate
npm run db:push
```

## أوامر مفيدة

```bash
npm run lint
npm run typecheck
npm run build
```

## الخطوات القادمة

1. إضافة تسجيل الدخول وإدارة الجلسات.
2. بناء لوحة إدارة العيادات والفروع.
3. بناء شاشات المرضى والمواعيد والزيارات.
4. تحويل قوالب التخصصات إلى إعدادات قابلة للتعديل من لوحة الإدارة.
5. إضافة الفواتير والاشتراكات والتنبيهات المناسبة للسوق العراقي.
